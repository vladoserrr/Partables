# Partables — Telegram Mini App

Новая основа Telegram Mini App с игровым залом, профилем, демонстрационными рейтингами и бонусом за ежедневный вход.

## Запуск

```bash
npm install
cp .env.example .env
npm start
```

Откройте http://localhost:3000.

## Переменные окружения

Смотрите .env.example. Не добавляйте настоящий BOT_TOKEN или другие секреты в Git.

## Что уже добавлено

- адаптивный интерфейс в тёмном casino-стиле;
- 12 карточек игровых режимов;
- экран режима с полем ставки, быстрыми кнопками и демонстрационной анимацией;
- разделы «Игры», «Топы», «Бонусы», «Профиль»;
- переключение дневного и недельного рейтинга;
- ежедневный демонстрационный бонус с датой по Москве;
- базовый Express-сервер и health endpoint;
- Telegram WebApp SDK и имя пользователя из Telegram, если приложение открыто внутри Telegram.

## Что пока НЕ подключено

Это начальный UI-прототип, не готовая production-система.

- серверная база данных и Telegram initData validation;
- реальные игровые движки, серверная генерация случайных результатов и аудит;
- реальные балансы, ставки и история транзакций;
- Telegram Stars invoice, проверка оплаты и защита от повторного зачисления;
- реферальные начисления и защита от накрутки;
- автоматические награды рейтингов по расписанию;
- административная панель, лимиты и мониторинг.

Текущие результаты топов — демонстрационные. Кнопка пополнения намеренно не создаёт платёж. Баланс и ежедневный бонус в прототипе локальные и не являются реальным платёжным учётом.

## Перед включением платежей и игр

Нужно отдельно проверить актуальные правила Telegram, требования платёжной системы и применимое законодательство. Не включайте платные ставки или денежные/обмениваемые призы до такой проверки. Все секреты храните только в переменных окружения. Сервер должен проверять Telegram initData и самостоятельно рассчитывать каждый результат и баланс.
